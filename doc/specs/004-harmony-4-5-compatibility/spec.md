# Feature Specification: Mate 手机适配

**Status**: In Progress  
**Priority**: P1

## User Stories

### US1 同一安装包运行（P1）

用户可以在 Mate 60 及后续 Mate 手机上安装同一 HAP，并完成快速记录、图片校正、
Vault 编辑和云端/NAS 同步的核心流程。

### US2 安全降级（P1）

低版本缺少安全存储能力时，应用不明文保存令牌或 NAS 密钥，而是在重启后要求
重新连接。

## Functional Requirements

- **FR-401** 首要适配设备必须包含 Mate 60，并纳入后续 Mate 手机的回归验证；
  不得依赖单一机型名称或厂商私有接口。
- **FR-402** 最低 HarmonyOS/API 版本必须根据 Mate 60 真机验证和所需系统能力确定，
  不再预先承诺 API 10 兼容。
- **FR-403** 核心运行路径必须对系统能力、权限、相机、文件访问、网络和存储失败
  提供可见降级，不得崩溃或静默丢失 Markdown 内容。
- **FR-404** 页面必须适配 Mate 系列的竖屏、横屏、安全区域、字体放大和不同屏幕
  密度；编辑、拍照、校正、附件预览和同步控件不得遮挡或不可操作。
- **FR-405** 登录状态必须优先使用系统安全存储，不能写入 Vault 或普通配置文件。
- **FR-407** 发布前必须在 Mate 60 和至少一台后续 Mate 手机上完成创建、编辑、
  拍照、四点校正、重启恢复和手动同步冒烟验收。
