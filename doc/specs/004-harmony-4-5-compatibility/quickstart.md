# Quickstart: Mate 手机验收

1. 使用 DevEco Studio 同步工程并配置签名。
2. 连接 Mate 60 真机，安装 debug HAP。
3. 选择已有 Obsidian Vault，创建每日笔记并用所见即所得编辑器记录。
4. 拍照、矩形裁剪、四点透视校正，强制结束后重新打开。
5. 分别连接 Google Drive、威联通 TS-251D 和极空间，执行上传、下载、取消和
   冲突测试；NAS 需覆盖局域网与外网。
6. 在至少一台后续 Mate 手机上重复核心流程。
7. 检查日志不包含 token、secret key、预签名 URL 或个人文件内容。
