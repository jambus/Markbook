# Markbook Constitution

**Version**: 1.1.0
**Ratified**: 2026-07-24
**Last amended**: 2026-07-28

## I. 本地文件是唯一事实源

笔记必须以可直接读取的 Markdown 文件保存，图片和附件使用相对路径引用。
数据库、索引和缓存只能由文件重新生成，不能成为导出或恢复的必要条件。

## II. 数据安全优先于便利

任何保存、同步、迁移和冲突处理都不得静默覆盖用户内容。并发修改默认保留
两份；破坏性操作必须可识别、可确认，并具备恢复路径。

## III. 拍照链路必须短且可靠

从编辑器到系统相机、附件落盘、Markdown 链接插入应形成单一事务式流程。
成功提示前必须确认图片和正文都已保存，取消或失败不得留下无引用临时文件。

## IV. 同步 Provider 隔离

Google Drive、NAS 等实现必须遵循统一同步契约。鉴权、远端协议、平台 SDK 和 UI
不得进入本地笔记仓储层；Android APK 与 HarmonyOS HAP 不得改变笔记文件格式。

## V. 隐私与最小权限

默认仅在设备本地处理内容。启用远端前明确告知数据去向。令牌和密码必须写入
Android 或 HarmonyOS 提供的系统安全存储，或仅在当前进程内短暂保留；不得写入
普通配置，也不得记录凭据、临时下载 URL 或笔记正文。

## VI. 可验证交付

纯逻辑分别使用 Android 单测与 Hypium 单测；文件、相机、后台和网络能力必须在
对应真实设备和系统版本验证。每个规格的验收场景通过后才能标记完成。

## Governance

所有 `plan.md` 必须包含 Constitution Check。修改本文件需说明原因、兼容性
影响及迁移方案，并提升版本号。规格与实现冲突时，以已批准规格和本文件为准。
