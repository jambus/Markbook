# 产品路线图

## M0 工程基线

建立 HarmonyOS Stage 工程、规格体系、真机调试和持续构建入口；以 Mate 60
及后续 Mate 手机作为首要适配和发布验收范围。最低系统版本根据 Mate 60 真机
验证和所需系统能力确定，不再预先承诺 API 10。

## M1 本地可用

完成已有 Obsidian Vault 的选择与读取；支持每日笔记、所见即所得编辑、自动保存、
文件夹浏览、全文搜索、标签和双向链接。退出并重启后数据保持完整。

## M2 丝滑拍照

从每日笔记拉起系统相机，支持直接插入、矩形裁剪和四点透视校正；同时保留原图
与校正图，并写入相对 Markdown 链接。覆盖取消、权限/系统异常、空间不足及
孤儿附件清理。

## M3 可控同步

优先交付 Google Drive 与 NAS 二选一同步目标，支持手动双向同步、可选自动提示、
增量状态、进度、取消、离线恢复、回收站同步和保留双份的冲突处理。使用威联通
TS-251D 与极空间 NAS 完成真实验证。

## M4 知识工作区

后续再评估反向链接视图、关系图谱、插件和华为应用市场发布适配。
