# 产品愿景

Markbook 是一款 HarmonyOS 原生、本地优先的 Markdown 笔记本。它保留
Obsidian 式普通文件的可控性，同时提供 OneNote 式低摩擦拍照记录，并允许
用户选择 OneDrive 或自有 NAS 作为同步目标。

## 目标用户

- 经常在现场、课堂、会议或旅途中混合记录文字与照片的人。
- 希望长期持有普通 Markdown 文件，而不被专有数据库锁定的人。
- 需要在手机、平板和电脑之间使用个人云盘或 NAS 的用户。

## 核心价值

1. 随时可取：笔记和附件是普通文件，可备份、迁移和被其他工具读取。
2. 快速记录：从正文拍照后自动落盘并插入链接，不打断书写节奏。
3. 同步可选：离线功能完整，远端仅是用户主动启用的复制与协作层。
4. 不丢内容：异常退出、网络中断和多端冲突都不能静默覆盖数据。

## 非目标（首版）

- 多人实时协作编辑。
- 服务端 Markdown 渲染或内容分析。
- 将笔记正文存入 Markbook 自有云服务。
- 在未经用户确认时自动上传本地内容。
