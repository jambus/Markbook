# Markbook 组件规范

## 共通规则

组件描述的是语义与状态，不规定具体框架。Android APK 与 HAP 可采用不同原生实现，但名称、结果、禁用条件和反馈必须一致。所有可点击区域应有清晰标签、可见焦点或按压反馈，并满足至少 44 × 44 dp 的触控目标（空间受限的图标操作通过增加热区满足）。

颜色必须同时搭配图标、文字或形状传达状态；正文、控件和图片边界需在深浅色与字体放大时保持可辨认。动态状态须能被辅助技术读出。

## 应用骨架

### 顶部栏

**用途**：显示当前上下文与页面级操作。

- 左侧：返回上级，或在根页面显示 Vault/导航入口。
- 中间：当前笔记标题或页面名称；标题过长省略，但可在详情或辅助标签中完整读取。
- 右侧：最多放两项最高频、与当前页面直接相关的操作。编辑器中为“拍照”和“保存”。
- 滚动内容不能遮挡顶部栏；遵守系统状态栏与横屏安全区域。

### 底部操作区

**用途**：承载编辑场景中的次要或多步骤操作。

- 不与系统导航手势冲突；出现键盘时仍保留当前输入位置可见。
- 有未完成的图片处理时，优先显示“取消”“重试”“插入”等下一步，而不是全局功能。

## 操作组件

### 主操作按钮

**适用**：一个页面或步骤中最重要且安全的下一步，如“选择 Vault”“插入照片”。

- 同一视觉区域只允许一个主操作；文字描述结果，不用“确定”。
- 执行中禁用重复触发，并显示进行状态；不阻塞阅读或编辑输入，除非当前步骤必须完成。
- 出错后恢复可用状态，保留用户输入，并提供明确的重试或替代操作。

### 次要按钮与图标按钮

**适用**：保存、返回、裁剪、旋转、删除等已知动作。

- 图标按钮必须有可访问名称；不使用没有标签的抽象图标表达关键操作。
- 删除、丢弃和覆盖为破坏性操作，使用明确文字及二次确认；如果可以，优先提供撤销。
- “取消”只放弃尚未提交的当前步骤，不得回滚已安全保存的笔记内容。

### 菜单与溢出操作

**适用**：设置、诊断、低频编辑功能。

- 菜单项用动词开头并按风险排序；破坏性操作与普通操作分组或隔开。
- 关闭菜单不产生副作用；菜单项不可用时给出原因或隐藏，不显示无响应入口。

## 信息与状态组件

### 保存状态

编辑器顶部或靠近标题处持续显示以下之一：

| 状态 | 触发 | 用户可见内容 | 行为 |
| --- | --- | --- | --- |
| 已保存 | 正文已写入 Vault | `已保存` | 可继续编辑 |
| 正在保存 | 防抖保存或手动保存进行中 | `正在保存…` | 防止重复手动保存 |
| 有未保存更改 | 编辑后、保存尚未开始或失败 | `未保存` | 保留内容并可手动保存 |
| 保存失败 | 写入或授权失败 | `保存失败` + 下一步 | 不清空编辑内容；可重试或重新授权 |

不可仅靠短暂 Toast 表示保存是否成功。

### 横幅与行内提示

**适用**：影响当前内容但不需要中断的状态，如 Vault 权限失效、冲突副本或索引重建。

- 放在受影响内容附近，说明影响、原因（可理解时）和主操作。
- 权限失效：提示当前 Vault 不可访问，主操作为“重新选择 Vault”；不自动新建 Vault。
- 冲突：说明原内容未被覆盖，并提供查看两个版本的位置。
- 用户主动关闭后，若状态仍存在，在合适位置保留可重新发现的入口。

### Snackbar / 轻提示

**适用**：不影响后续操作的短暂成功反馈，如“已插入照片”。

- 重要结果必须也能从页面状态或内容中验证。
- 若操作可撤销，提供单个清晰的“撤销”动作，并说明撤销范围。
- 系统相机或文件选择器的取消不显示轻提示。

### 加载、空与错误状态

| 场景 | 必须包含 | 禁止 |
| --- | --- | --- |
| 加载 | 正在进行的对象或骨架；超过短暂等待时给出文字 | 空白页面或无限转圈无说明 |
| 空 | 原因、用户价值和一个下一步 | 将空状态误写成错误 |
| 错误 | 影响、可行下一步、保留内容的说明 | 只展示“发生错误”或技术异常 |
| 无权限 | 所缺权限与重新授权入口 | 静默降级到私有目录 |

## 内容组件

### 笔记列表项

显示标题（或首行替代）、相对日期/修改时间和必要的内容摘要。长按或菜单中的删除进入回收站，不做立即永久删除。空标题使用“未命名笔记”仅作为显示标签，不自动改名。

### Markdown 正文与图片

- 正文优先连续阅读和输入；列表、链接、标签和 `[[双向链接]]` 的显示必须保留其 Markdown 语义与可编辑性。
- 图片应保留原始宽高比，加载中使用稳定的占位区域，加载失败显示相对路径与重试入口。
- 点击图片进入查看或编辑上下文，不应破坏正文选择与光标位置。

### 表单与选择器

标签始终可见，错误靠近字段并描述修复方法。调用系统 Vault 选择器或相机前，先在应用内说明目的；系统界面取消返回后保持原页面与编辑内容。
