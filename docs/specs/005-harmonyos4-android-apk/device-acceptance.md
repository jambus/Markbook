# Mate 60 HarmonyOS 4 验收清单

## 前置条件

- Mate 60 使用 HarmonyOS 4，开启开发者模式和 USB 调试。
- 连接后保持手机解锁，并在手机上确认本电脑的 USB 调试/调试密钥授权提示。
- 准备一个已有 Obsidian Vault，并确认电脑端 Obsidian 可以打开它。
- 使用仓库生成的 `android/app/build/outputs/apk/debug/app-debug.apk`。

连接设备后可运行 `./scripts/install-apk.sh` 自动选择 `adb` 或 `hdc` 安装 APK。
若脚本提示 `connect-key`，表示已发现设备但尚未确认调试密钥；先在手机确认授权，
再重新运行脚本，不要继续执行后续验收。

## 验收步骤

1. 安装 APK，记录设备型号、HarmonyOS 版本、Android 兼容层 API、APK 版本。
2. 首次打开应用，选择已有 Vault；确认没有生成 Markbook 私有副本或数据库。
3. 编辑当天笔记，输入中文、标题、列表和图片链接；等待自动保存，再执行手动保存。
4. 关闭并重新打开应用；确认当天笔记内容仍在原 Vault 中。
5. 拍照后分别测试“矩形”和“四点校正”，拖动四个角点完成透视变换并插入。
6. 检查 `assets/<笔记文件名>/` 中存在同一拍摄 ID 的 `o` 和 `c` 两个文件；新文件名
   为 `<HHmmss>-<xxxx>-o.jpg` 与对应的 `c` 文件，Markdown 使用
   `../assets/<笔记文件名>/` 相对链接。
7. 在照片保存或编辑保存过程中强制结束应用，再启动并检查临时文件、备份文件、
   事务标记和 Markdown 是否能恢复，不得出现孤儿附件或静默副本。
8. 在系统设置中撤销目录权限，重新打开应用；确认提示重新选择 Vault，重新授权后
   可以继续编辑原目录。
9. 在电脑 Obsidian 中打开同一 Vault，确认中文、笔记和校正后的图片均可显示。

## 记录结果

记录每一步的通过/失败、截图、日志、设备信息和生成文件名。任何未执行的步骤都
不能标记为通过；该清单完成前，Android 里程碑保持未验收状态。
