# Quickstart: 本地笔记验收

在 Mate 手机上，系统文件选择器不支持目录选择时，请选择 Vault 内任意 `.md` 文件；
禾记（Heji Notes） 会将该文件所在目录作为 Vault 根目录。2-in-1 设备可以直接选择 Vault 目录。

1. 安装并启动应用，创建两篇标题相同的笔记。
2. 输入中文、Markdown 列表、链接和 10,000 字正文。
3. 返回列表并强制结束应用，再次启动。
4. 确认两篇笔记均存在、内容完整、排序正确。
5. 搜索正文中的唯一关键字并打开正确笔记。
6. 删除一篇笔记，从回收站恢复并再次打开。
7. 复制整个 `禾记（Heji Notes）/` 到测试环境，确认可重建列表和索引。
