# Quickstart: 同步验收

## Google Drive 配置

1. 按 `android-google-oauth-setup.md` 配置 Google Drive API 和 Android OAuth
   测试客户端；不要在仓库中保存客户端密钥。
2. 在“同步”中选择 Google Drive，完成系统 Google 账号授权。
3. 选择与电脑 Obsidian 对应的 Vault 根目录，确认首次同步范围后再上传。

## NAS 配置

1. 准备威联通 TS-251D 或极空间的远程访问，并分别验证局域网、外网地址。
2. 在“同步”中选择 NAS，填写经验证协议所需的地址、目录和凭据。
3. 确认 Markdown 与照片附件参与同步；`.obsidian/`、本地 `.trash/`、临时文件、索引、
   凭据和同步基线不上传。
4. 确认凭据使用安全存储；同步范围和远端目标在首次上传前明确展示。

## 验收

先运行协议无关的 Provider、规划器、基线编解码、冲突保留和故障注入测试，再构建
当前待验收的平台客户端。随后在两个独立安装实例和测试远端执行：

1. 设备 A 创建含三张照片的笔记并同步到空远端。
2. 设备 B 首次同步，确认 Markdown 和所有相对图片引用可用。
3. A、B 离线修改同一笔记，再依次同步。
4. 确认产生清晰命名的冲突副本，两份内容均未丢失。
5. 在上传大图中途断网并结束应用，恢复网络后重试。
6. 确认远端无半文件，本地内容完整，同步基线未提前更新。
7. 使凭据失效，确认应用要求重新认证且日志不含敏感值。
8. 取消授权与进行中的同步，确认 UI 可恢复且旧基线保持不变。
